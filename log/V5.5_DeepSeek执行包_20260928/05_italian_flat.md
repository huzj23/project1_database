# 05：Italian Flat——盒子撞动原场景瓶/杯

前置：01–04通过，先阅读09的共用渲染规范。本关目标是一段可看清“盒子下降 → 接触瓶 → 瓶倾斜/平移”的视频，为后续场景提供完整技术样例。

## 1. 已知资产事实

V5.4审计：525对象、476Mesh、13盏作者灯；无刚体/软体/布料/碰撞modifier。作者原镜头 `Cam Living`。网格 `Table` 和 `Table.001` 的顶部分别约0.500、0.515（源数值，米制待核验），名称相似不能证明是同一支撑面。

`Bottiglia Cristallo` 约0.112×0.112×0.236，`Bicchiere Cristallo` 约0.080×0.080×0.104，另有第二只杯、`Tappo Cristallo`、`Vassoio` 托盘。对象独立，瓶/杯可提取。AABB推测支撑关系只是候选，要用网格射线与视觉图确定瓶究竟落在托盘、桌面还是其他几何上。

`Sofa*`、`Pillow.001`、`Pillows`、`Chocofur_Rug_12`、`Pouf_rounded_3types_002` 全部没有软体设置。建立软陈设禁入清单，不能只看名称；运行代理目视补全未命名软物。

## 2. 具体操作

1. 原场景同作者机位渲染/复用已验收基准图，核对哈希和材质。保留原文件。
2. 输出边桌俯视定位图和瓶/杯/托盘三视图；写支撑关系、对象尺寸、可用落点、相机候选和软陈设距离。
3. 选择一只瓶作为主目标。若瓶塞紧闭，可与瓶合并为声明的刚体assembly；若瓶塞松放，应独立仿真或避开该瓶。不能视觉上有松盖但物理上无理由焊死。
4. 首轮托盘/桌均被动，瓶主动；杯和其他物体若在扫掠范围内必须建被动/主动collision或改变落点避开。后续扩成两级才将第二杯也设主动。
5. 选约0.12–0.18 m的真实小盒，碰撞起点先设盒底高于瓶顶约0.15–0.35 m，水平偏置瓶半径与盒边界，使下落盒的一条边击中瓶肩/侧面；纯正中落下可能只有竖向挤压，需用诊断确认有可见倾倒力矩。
6. 目标先静置，正式t=0释放盒，仅重力运动。偏置/高度搜索最多12次，每次保存原因；不能接触后给瓶另加速度。
7. 检查路径、瓶的倒向和所有潜在碰撞面；若会落向软家具，换方向或合理截取镜头。完整已输出片段内禁止穿透/软接触；剪切不能隐藏已经发生的失败。
8. 相机从桌面侧方略高处取景，镜头瞄准瓶中段和落盒路径；优先低俯角与可见碰撞，不能只坚持绝对“人眼高度”导致桌边挡住瓶。

## 3. 明确的验收指标

- 至少0.3秒接触前可见下降、至少0.5秒目标响应；不足时提高镜头内起点/延长记录，而非重复慢放帧。
- 盒/瓶首次接触、瓶启动、瓶最终位移/角度齐全；瓶平移至少3 cm或倾斜至少20°，视觉上能辨认。
- 无触发对照中瓶稳定；全片没有对瓶设定外部速度/力；桌面/托盘无明显穿透。
- 软陈设禁入区在每物理子步检查。镜头可在瓶掉出桌边后结束，但应有自然收尾；不渲染玻璃破碎。
- 13盏作者灯及World/材质保留；变化仅为已声明盒子、原瓶的动态绑定和相机。
- 预览图显示所有模型尺度合理，无动态瓶和原静态瓶重影。

## 4. 失败分支

盒太大：选择更小的已批准盒，不能任意压缩模型。瓶不动：先确认主动角色、质量/惯量、碰撞双份，再调几何落点。瓶先自行倒：返回03修底部/支撑关系。无空间安全倒下：优先该边桌另一方向；确实不行则用原厨房桌已有 `vase` 做替代样例，并将“原要求瓶碰撞未完成”单独列出，不能静默算通过。

碰撞杯需要凸分解、效果不好时先保留瓶版本，杯是后续增强。不要为加入第二级而延迟第一段合格盒撞瓶交付。
