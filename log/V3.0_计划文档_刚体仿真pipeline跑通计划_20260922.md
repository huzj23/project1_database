## 0. 任务目标（本次变更的核心）

### 0.1 旧目标（终止）

追求"生活化、高真实感"的大规模资产生成；并尝试软体仿真。

### 0.2 新目标（生效）

> **跑通一条"真实场景 + 真实物体（刚体）"的仿真 pipeline。
> 验收标准：七种运动，每种产出一条质量较好的样例视频。**

这个目标把范围收窄到**可验证、可交付**的程度：不再追求画面风格的完美，
而是先证明**这条链路是通的、物理是真的、每种运动都能出片**。

### 0.3 明确的非目标

| 不做 | 原因 |
|---|---|
| **软体仿真** | **这是建模问题**——GSO 只提供表面网格（无体网格），`collision.type: convex_hull` 是刚性表示。四面体化 + 软体求解是独立的建模课题，不在本轮范围 |
| 大规模批次（36 条/100 条） | 先每种运动出一条合格样例，通过后再谈规模 |
| 街道/运动场等外部场景 | 那属于学长自己做的资产；我们本轮只用**已有的 5 个 ReplicaCAD 室内** |
| 背景风格进一步美化 | 室内真实度已确认"够用" |

### 0.4 软体的边界：允许"一点球的弹性形变"

按你的要求，软体不做，但**球形物体允许考虑一点弹性形变**。
实现上这不需要软体求解器——通过**恢复系数（restitution）**即可表达：

| 物体 | restitution | 表现 |
|---|---|---|
| 球类（篮球/足球/排球/棒球） | 0.70 – 0.85 | 明显弹跳，符合直觉 |
| 木盒 / 纸盒 | 0.25 – 0.40 | 弹一两下就停 |
| **毛绒玩偶** | 0.05 – 0.15 | **几乎不弹，落下即停**（这本来就是真实行为） |

## 1. 仿真引擎与物理表示（事实记录）

| 项 | 事实 |
|---|---|
| **引擎** | **PyBullet（Bullet Physics）**，经 Kubric 的 `simulator.PyBullet` 调用 |
| 性质 | **真刚体动力学引擎**：解算接触、摩擦、恢复系数、滚动/自旋摩擦；不是单纯的数值积分 |
| 积分 | 物理步长 240 Hz（`physics_fps`），渲染按 `video_fps` 采样 |
| 物体表示 | `collision.type: convex_hull` + URDF 碰撞网格 |
| **软体通路** | **pipeline 中不存在**（grep `loadSoftBody` / `soft_body` / `deformable` 无实现） |

**结论**：小熊"像铁做的"是**表示方式**决定的，不是 bug。本轮接受这一表示。

## 3. 本轮必须解决的四项技术问题

按你指定的顺序：

### 3.1 加大落差（提高运动帧占比）

**实测问题**：81 帧中**仅 9 帧有运动（11%）**，72 帧是静止物体。

**根因**：0.45 m 落差在 g=9.81 下只需 **0.30 秒**，16fps 下约 **5 帧**。

**做法**：
1. **加大落差**：0.45 m → **1.2–1.8 m**（桌子高度量级，合理）
2. **降低 video_fps 做成慢动作**：物理仍 240 Hz，video_fps 16 → **8**，运动帧数翻倍
3. **按运动长度裁剪视频**：不再固定 81 帧

**验收**：运动帧占比 **≥ 50%**。

### 3.2 换更开阔的支撑区域

**实测问题**：现有净空区是 **1.0 × 5.4 m 窄走廊**（x 2.20–3.20），相机退到墙边，**约 1/4 画面被墙遮挡**。

**做法**：重新扫描地板，筛选标准改为：
- 不只是"无家具"，还要**离墙面有足够余量**（相机站位所需半径）
- 优先**房间中央**而非走廊
- 记录验证方法（`raycast_grid` + 相机半径检查）

**验收**：相机四周到墙的最小距离 ≥ 相机站位需求；**画面无墙体遮挡**。

### 3.3 提升分辨率

**现状**：1280×720（学长规格）。**做法**：提升到 **1920×1080**。

### 3.4 相机不被遮挡

与 3.2 联动；另可在场景资产里固定方位角约束。

## 4. 七种运动与验收标准

| # | 运动 | 来源 | 适配物体 |
|---|---|---|---|
| 1 | **匀速（滚动/平动）** | 学长 `rolling` | 罐、收纳盒、球 |
| 2 | **匀加速** | 学长 `constant_force` | 收纳盒、罐（外力驱动） |
| 3 | **自由落体** | 学长 `free_fall` | **毛绒玩偶**、球 |
| 4 | **抛体** | 我们新增 | 球、玩偶 |
| 5 | **圆周（转盘带动）** | 我们新增 | 桌游盒、花盆 |
| 6 | **转盘自转** | 我们新增 | 陶盆、花盆 |
| 7 | **阻尼** | 我们新增 | 收纳盒、罐 |

**每条样例的验收标准**：

| 项 | 标准 |
|---|---|
| 物理校验 | `validation.valid == True`，`reasons` 为空 |
| 穿模 | `max_surface_penetration == 0`（求解器保证） |
| 运动帧占比 | ≥ 50% |
| 画面 | 无墙体遮挡；主体占画面宽 15–35% |
| 分辨率 | 1920×1080 |
| 产物 | rgb/depth/segmentation + video.mp4 + trajectory.json + collisions.json + metadata.json |
