## 4. 弧线：改初始布局后重新求解，不弯折旧动画

先用9盒，链中心弧长约1.2–1.5m；建议初值半径约1.3–1.8m、总转角约45–60°。这些量不是独立选项，按实际中心距计算，不能同时机械指定不相容数值。弧度需在所选镜头中明显可见：建议中心线相对首尾弦的屏幕最大偏离至少约30px（720p），最终以用户图判断为准。

局部地面坐标为U、V，路径采用：

```text
phi_i = phi_0 + s_i / R
p_i = centre + R*cos(phi_i)*U + R*sin(phi_i)*V
tangent_i = -sin(phi_i)*U + cos(phi_i)*V
相邻转角 Δphi ≈ 中心弧长间距 p / R  （弧度）
```

将盒子的**预期倾倒方向/厚度轴**朝向路径切线，宽度方向横跨路径，竖轴符合实际支撑。不要把盒子宽边误当倾倒轴。旧评审文件中“2πR/间距”为角度的表述不正确，不得照抄。

1. 先复用旧已成功的有序盒对和质量/摩擦基线，3–4盒验证弯向传递；不重新做全部资产扫描。
2. 旧直线中心距只作初值。弯曲后按旋转后的OBB检查两侧最近面间距、初态互穿和目标面的有效重叠；不能把统一0.155m当保证。
3. 默认维持已证明可传递的三款循环顺序，通过弧线、真实背景和透视解决机械平铺感，不同时随意改变资产顺序、尺寸与全部物理参数。
4. 弧线直接生成初始位姿，然后完整重新求解。绝不能将旧直线轨迹逐帧映射到圆弧，或让渲染模型转弯而物理代理仍走直线。
5. 若传播失败，顺序为：检查轴向与接触 → 调对应盒对间距 → 适度加大半径但仍有可见弧度 → 从10/9盒减至8盒。禁止回退成直线或靠脚本逐盒补推。
6. 固定一次触发；全链倒下，无旁路。保持无触发对照、一次断链对照、重复运行及半dt核验。旧直线28/28不能移植为新链PASS。

有效密度200kg/m³是盒内填充近似参数，不是测得纸板材料密度；保留质量来源和不确定性。不要为让新链通过就无依据地修改个别盒质量或摩擦。

诊断必须读取完整写入轨迹的`replay.blend`，或明确逐帧将轨迹施加到对象。先断言至少一个目标盒在初、中、末帧的世界矩阵不同，并与轨迹一致；同时断言活动相机与获批配置一致。失败则停止，不能重复检测静态初态却报告“全程无穿模”。

采集经过依赖图求值的网格和世界变换，包含生效的修改器/实例；检查所用对象集合与实际渲染集合一致。保留已修好的body-to-visual完整矩阵、独立实例ID及原尺寸校验。

### 8.2 不再用“相交三角形数等于零”当所有碰撞的总判据

正常接触、接触容差、扫描表面噪声与真实穿插要区分。三角形相交数不是穿透深度；完全包含也可能没有表面交线。顶点到表面的最小距离是近似上界，不能用它证明“所有表面至少相隔该距离”。

| 检查对象 | 要求 |
|---|---|
| 初态盒—盒、盒—非支撑实体 | 不重叠；用OBB/凸代理及必要的视觉网格窄相位，排除包含和遗漏实例 |
| 全过程盒—盒 | 真接触允许，记录子步最大负接触距离和视觉渗入；超过2mm必须修，明显可见穿插无论数字都拒收 |
| 盒—声明支撑面 | 真接触允许；稳态悬空/下穿目标≤1mm，硬上限2mm；先消除代理膨胀、中心偏移、双重变换，不抬高物体遮掩 |
| 盒—非预期真实场景实体 | 不得穿越；初态及倒下扫掠区域保持净空，不因为没放进求解器就忽略 |
| 布光辅助物 | 按第3节已审定角色处理；不是一律加成碰撞墙，也不是一律隐藏 |

2mm是数值安全上限，不是允许视觉造假的目标。盒间全过程OBB/接触距离覆盖全部物理子步；高成本视觉窄相位覆盖全部视频帧并对接触±0.15s加密。场景先用运动包络筛出近邻，禁止每次重复重建390万三角形做无差别全对扫描。

最终必须：所有8–10盒依次倒下、一次真实触发、无直接撞后续盒的旁路；无触发全片稳定；断链下游停止；重复与半dt结果在顺序及完成性上相符。批准的是视觉方案，不免除这些检查。

```text
剩余预计时间 = 尚未完成的准备/验证
             + 需要重新加载的成本
             + 1.25 × 剩余帧数 × 实测保守热帧耗时
```
