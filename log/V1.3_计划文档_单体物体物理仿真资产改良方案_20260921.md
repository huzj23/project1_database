## 1. 结论速览

同事的效果更好，**不是因为用了更复杂的场景，而是因为一套"影棚产品摄影"配方**。
他们的背景只有三样东西：**地板 + 背景墙（cyclorama）+ HDRI**，再加**三点柔光灯**。

我们把 6 个压缩包全部拆开分析后，得到了完整配方；并**已在本机管线验证可复现**。

同时，你 `data_found_online` 里已有的 **ReplicaCAD 交互场景**与 **GSO 物体库**经实测
**可以直接用于本管线**，可以做出与同事"同类但不同"的可交互背景。

## 2. 同事方案的完整逆向分析

### 2.1 信息来源

| 文件 | 内容 |
|---|---|

| `*/frames/*.png` | 1.0–1.4 MB 无损帧 |

### 2.2 关键设置（来自 `render_settings.json`）

```json
{
  "resolution": [1280, 720],
  "fps": 24,
  "renderer": "Cycles",
  "samples": 24,
  "camera_location": [2.5, -20.0, 8.5],
  "focal_length_mm": 55,
  "motion_blur": true,
  "shutter_frames": 0.25,
  "ball_color": "matte deep blue",
  "assets": {
    "concrete": "https://polyhaven.com/a/concrete_floor_worn_001",
    "hdri":     "https://polyhaven.com/a/empty_warehouse_01"
  }
}
```

第 6 组（`circular_track_friction`）另有：`samples: 16`、`shutter 0.22`、
`block_material: terracotta orange`、`rails_material: graphite anodized metal`、
`hdri: https://polyhaven.com/a/studio_small_09`、内外轨道半径 1.34–1.42 / 1.78–1.86 m。

### 2.3 渲染环境（来自 `render.log`）

| 项 | 值 |
|---|---|
| Blender | **4.5.13 LTS**（远新于我们的 3.4.1） |
| 加速结构 | **OptiX** → 走 **GPU** |
| 降噪 | **加载了 OptiX 降噪内核**（AI 降噪） |
| 场景物体 | `Floor`、`Back Wall`、`Large Softbox`、`Front Fill`、`Cool Wall Rim`、`Genesis Ball`、`Sphere`、`Cube.001` |

**这是最重要的发现**：他们不是"用一个 HDRI + 一块地板"，而是搭了
**影棚置景（地板 + 背景墙）+ 三点布光（大柔光箱主光 + 正面补光 + 冷色轮廓光）**。

### 2.4 差距逐项对照

| # | 维度 | 同事 | 我们（V1.2） | 影响 |
|---|---|---|---|---|
| 1 | 分辨率 | **1280×720** | 768×432 | 2.8× 像素量 |
| 2 | 帧格式 | **PNG 无损**（~1.2 MB/帧） | JPEG q95（~20 KB/帧） | **清晰度差距主因** |
| 3 | 运动模糊 | **开启，快门 0.22–0.25** | **关闭** | 运动质感 |
| 4 | 布景 | **地板 + 背景墙（cyclorama）** | 单块地板 | 空间感/背景 |
| 5 | 布光 | **三点柔光箱** | 2 个平行光 | **光照差距主因** |
| 6 | 地面材质 | **Poly Haven PBR 混凝土** | 纯色灰 | 真实感 |
| 7 | 材质命名 | matte / anodized 等分档 | 基础 Principled | 质感 |
| 8 | 镜头 | 55 mm | 42 mm | 透视 |
| 9 | 引擎 | Blender 4.5 + OptiX | Blender 3.4 内核 | 性能/画质 |
| 10 | 采样 | 16–24（靠 AI 降噪） | 64（OIDN） | 速度 |
| 11 | 帧数 | 12–96 | 96 | 相当 |

> **结论**：清晰度主要输在 **分辨率 + PNG 无损**；光照主要输在 **三点柔光箱 + cyclorama**；
> 背景差距其实**很小**——他们的背景就是影棚，不是复杂三维场景。

### 3.3 需要绕开的一个坑

**ReplicaCAD 烘焙版（BakedLighting）不能直接导入**：它把光照烘焙进第二套 UV 的
lightmap，靠自定义着色器还原；普通 glTF 导入会得到错乱的品红/紫色着色（已实测复现）。
→ **改用非烘焙的 `ReplicaCAD_Interactive` 版本**（实测画质很好）。

另有一个兼容性问题**已修复**：Blender 3.4 的 glTF 导入器调用 `np.bool`，
而 NumPy 1.24+ 已移除该别名 → 已在 `phyco_common.patch_numpy_legacy_aliases()` 中补齐
（同时补 `int/float/complex/object/str/long/unicode`）。

## 4. 改良方案

### 4.1 总体思路

```
                ┌── Track A 视觉对齐：照搬同事影棚配方（立刻见效）
改良方案 ───────┤
                ├── Track B 可交互背景：ReplicaCAD + GSO（差异化优势）
                └── Track C 兼容与工程化：着色器/许可/流水线
```

**Track B 是我们的差异化点**：同事只做了影棚白背景，而我们有
**照片级室内场景 + 90 个带物理参数的家具 + 1033 个 GSO 物体**，
可以把"单体无交互"升级为"真实环境中的单体运动"，且背景本身可交互。

### 4.2 Track A —— 视觉对齐（照搬同事配方）

| 项 | 现值 (V1.2) | **改为** | 依据 |
|---|---|---|---|
| 分辨率 | 768×432 | **1280×720** | 同事 |
| 帧格式 | JPEG q95 | **PNG 无损** | 同事；清晰度主因 |
| 运动模糊 | 关 | **开，shutter 0.25** | 同事 |
| 布景 | 单地板 | **地板 + 背景墙 cyclorama** | 同事场景图 |
| 布光 | 2× 平行光 | **三点柔光箱**：Large Softbox（主）+ Front Fill（补）+ Cool Wall Rim（轮廓） | 同事场景图 |
| 地面材质 | 纯色 | **Poly Haven PBR 混凝土** | 同事 |
| 环境光 | HDRI 随机 | **HDRI（含 `empty_warehouse_01`，与同事同款）** | 同事 |
| 镜头 | 42 mm | **55 mm** | 同事 |
| 采样 | 64 | **32 + 降噪**（CPU 用 OIDN） | 同事用 16–24 + AI 降噪 |
| 材质 | 基础 | **按档命名**：matte / glossy / anodized | 同事 |

> Blender 升级到 4.5 与 OptiX AI 降噪**不在本期**（会推翻已验证的 3.4.1 环境，
> 且 GPU 深度通道在本机栈上会崩）。本期先用 **分辨率 + PNG + 柔光箱 + 运动模糊**
> 拿下大部分画质差距，Blender 升级作为后续独立议题。

### 4.3 Track B —— 可交互背景（差异化）

**B1. 室内场景背景（ReplicaCAD Interactive）**

- 6 个 stage：`frl_apartment_stage` + `Stage_v3_sc0..sc3`（
  另有 84 个家具排布变体可作构图多样性）
- 以 `simulation_filename=None` 作为**纯渲染背景**接入，不干扰物理
- 相机自动取景改为**在房间内选点**（用 stage 包围盒约束）
- 运动物体在室内地面/台面上运动 → 背景有真实景深与材质

**B2. 可交互家具道具（ReplicaCAD objects + URDF）**

- 90+ 个 `.glb`（视觉）+ 12 个 `.urdf`（含质量/摩擦/弹性、可动关节）
- 可作**真正的物理参与者**（例如"物体撞到椅子""门被推开"），
  为后续"有交互"场景打基础

**B3. 通用物体库（GSO）**

- 1033 个 Kubric 原生物体，`data.json` 直接给出 bounds/mass
- 类别覆盖鞋、日用品、玩具、瓶罐、包、桌游、手办、积木…
- 建议先取 **子集**（见 §5.2），避免一次性搬运 12.4 GB

**B4. PBR 材质库**

- `dirty_football_4k` 已验证可用（命名与 phyco-sim 加载器匹配）
- 建议再从 Poly Haven 取 4–6 个 CC0 材质做地面/墙面变化

### 4.4 Track C —— 工程化

1. **兼容层**：`patch_numpy_legacy_aliases()`（已完成）
2. **资产注册表扩展**：`phyco_common.ASSETS` 增加三类来源
   （`phyco_sim_objs` / `gso` / `replicad`），统一 `get_asset()`
3. **背景构建器**：`phyco_backdrops.py`
   - `build_cyclorama()` —— 影棚（Track A）
   - `build_replicad_stage()` —— 室内（Track B）
   - `build_studio_rig()` —— 三点柔光箱
4. **渲染档位 preset**：`--look studio` / `--look interior`
5. **许可合规**：产物 `metadata.json` 记录 `asset_license` 字段
   （Poly Haven CC0 / ReplicaCAD CC BY 4.0 / GSO CC BY-SA 4.0）

## 6. 验收方式（与同事对比）

对同一物理参数（如圆周运动 radius=1.2 / period=2.0）各出一版，做三项对照：

| 指标 | 检查方法 | 目标 |
|---|---|---|
| 清晰度 | 帧文件字节数 + 有效分辨率 + 高频能量 | 达到同量级（PNG，≥1 MB/帧 @1280×720） |
| 光照 | 直方图分布、阴影柔度、高光形状 | 柔和阴影、无硬边 |
| 背景 | 目视 + 背景区域熵 | 有材质细节，非纯色 |
