### 2. 新增 `src/physim/safe_output.py`（无删除输出层）

用**移动**替代**删除**，提供：

| 函数 | 作用 |
|---|---|
| `allocate_run_dir(base, run_id, workspace_root=)` | 每次运行分配独立目录；目录已有输出则**拒绝复用**（`OutputConflictError`） |
| `quarantine(paths, workspace_root=, remove_root=, reason=)` | 移动到 `remove/<时间戳>/<原相对路径>`，移动前后校验 sha256，写 `move_manifest.json` |
| `quarantine_stale_frames(scratch, ...)` | 旧 `purge_stale_frames` 的替代 |
| `find_workspace_root` / `resolve_workspace_root` | 工作区发现；无法确定时**报错而非删除** |

所有目标路径 `resolve()` 后断言位于工作区内，越界即拒绝。**本模块不调用任何删除原语。**

### 3. 修改 `src/physim/render/blender_backend.py`（消除实际删除调用）

`purge_stale_frames()` 原实现直接 `f.unlink()`，且被 `build_scene()` 每次渲染调用。
改为调用 `safe_output.quarantine_stale_frames()`：

```python
# 改造前
f.unlink()                       # <- 唯一一处真实文件删除
# 改造后
quarantine_stale_frames(root, workspace_root=ws, remove_root=remove_dir)
```

签名新增可选 `workspace_root=` / `remove_root=`；**工作区未知时不删除**，只在 stderr 报告并
返回 0（保留帧是可恢复的，删除不是）。
