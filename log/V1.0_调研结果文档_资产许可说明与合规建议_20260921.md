## 2. CC BY-SA 4.0 到底是什么

**它不是"商业许可"，而是"开放许可"**——这类许可的目的恰恰是**允许**别人使用，
只是附带条件。Creative Commons 的缩写逐字含义：

| 缩写 | 含义 | 说明 |
|---|---|---|
| **CC** | Creative Commons | 知识共享许可体系 |
| **BY** | Attribution | **必须署名**原作者 |
| **SA** | ShareAlike | **相同方式共享**：衍生作品必须用同样（或兼容）的许可发布 |

所以 CC BY-SA 4.0 = **署名 + 传染性开源**。它**允许商业使用**。

常见许可的宽松程度排序（从宽到严）：

```
CC0  <  CC BY  <  CC BY-SA  <  CC BY-NC  <  CC BY-NC-SA  <  保留所有权利
无限制    要署名    要署名+传染    要署名+禁商用    两者都要       不可用
```

**易混淆点**：`SA`（ShareAlike）和 `NC`（NonCommercial）是**两个不同的限制**。
- `SA` 限制的是**别人怎么再分发**（必须同样开放）
- `NC` 限制的是**能不能赚钱**

## 3. 实测核对结果

### 3.1 GSO —— 全部 1033 个对象都是 CC BY-SA 4.0

逐个读取 `GSO.json` 中每个资产的 `license` 字段的统计结果：

```
CC BY-SA 4.0    1033  (100.0%)
```

抽查 5 个对象的 `data.json`，`license` 字段均为 `CC BY-SA 4.0`。

### 3.2 ⚠️ ReplicaCAD —— 实际是 CC BY-NC 4.0，不是 CC BY 4.0

**该数据集自相矛盾**，需要以 `LICENSE.txt` 为准：

| 文件 | 声明 |
|---|---|
| `README.md` 前言 | `license: cc-by-4.0` |
| `README.md` 正文 | "All materials are licensed under ... CC BY 4.0" |
| **`LICENSE.txt`（法律文本）** | **`CC BY-NC 4.0`**，明确写有 "**NonCommercial: You may not use the material for commercial purposes.**" |

HuggingFace 仓库页的标签也写 `license:cc-by-4.0`，与仓库内 `LICENSE.txt` 冲突。
**合规上应以 `LICENSE.txt` 为准**（那是完整的许可法律文本）。
→ 因此本项目按 **CC BY-NC 4.0** 对待 ReplicaCAD。

## 4. 对你们研究的两个实际影响

### 4.1 GSO 的 ShareAlike：影响"数据集公开"这一步

CC BY-SA 4.0 第 3(b) 条区分两种情况：

- **汇编（Collection）**：把授权素材与其他独立作品放在一起 → SA 只作用于 GSO 那部分，
  不"传染"到你们的其他内容；
- **改编（Adapted Material）**：对素材做了改造 → 衍生作品必须按 CC BY-SA 4.0（或兼容许可）发布。

**由 GSO 三维模型渲染出的视频，通常会被认定为对该模型的"改编"**，所以：

> 如果你们把这批视频作为数据集**公开发布**，需要
> ① 署名 Google Scanned Objects；② 以 CC BY-SA 4.0 兼容许可发布（至少是含 GSO 的那部分）。

这在学术论文/数据集发布中是常规且可接受的，但如果你们的机构或投稿方要求数据集采用更宽松的
许可（例如 CC BY 4.0 或无限制），就会冲突。

### 4.2 ReplicaCAD 的 NonCommercial：影响"将来能不能商用"

- 学术研究、论文、非商业竞赛 → ✅ 没问题
- 将来若要把基于该资产的模型/数据用于**商业产品** → ❌ 需要重新授权或换掉资产

## 5. 建议做法（已纳入方案）

1. **在每条产物的 `metadata.json` 中记录 `asset_license` 字段**，逐条可追溯；
2. 输出目录附 `ATTRIBUTION.md`，列出：
   - Google Scanned Objects（CC BY-SA 4.0）
   - ReplicaCAD / FAIR（CC BY-NC 4.0）
   - Poly Haven（CC0，可选择性致谢）
3. **区分两类产物**，便于将来按许可拆分：
   - 用 **Poly Haven（CC0）** 的影棚方案 → 许可最干净，可自由使用
   - 用 **ReplicaCAD（NC）** 的室内方案 → 仅限非商业
4. 若将来需要"完全无限制"的资产：**Poly Haven 是 CC0**，可作为替代来源扩展影棚布景种类
   （换地面/墙面材质、换 HDRI 即可获得多样背景，且无任何许可负担）。

> 以上为基于许可文本的技术性解读，供你们判断参考。如果数据集要正式公开发布，
> 建议再与导师或学校成果转化/知识产权部门确认一次——尤其涉及 SA 的发布许可选择。
