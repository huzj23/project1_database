## 2. 新故事、约束与画面目标

**球抛射 → 撞击收音机机身 → 收音机在桌上倾倒 → 推倒/推出 R → R 单独跌落 → 地面混合骨牌 → 胶带短程滚动接力 → 另一段大小不同的骨牌/厚包装盒倒伏。**

原生收音机是必须成功的“物体与场景交互”。末端原生锈罐可作为加分接力；原生清洁剂瓶存在非闭合壳问题，不为保留旧 H1→H2 设计而再引入一条高风险必选机制。若末端不启用这些道具，保留其原位、外观与必要的静态碰撞，不移走、不隐藏。

| 对象/动作 | 硬要求 |
|---|---|
| B：球 | 首选已有硬质球/台球资产；抛射由初始位置、速度、重力产生，不手画飞行轨迹。首次碰撞应落在收音机机身，而非细天线 |
| A：原生收音机 | 保留作者初始位置和外观；被球撞后有明显倾倒，最终仍留在原生桌面上，不掉下桌、不穿墙/穿桌、不被隐形约束固定 |
| 天线/把手 | 查清是否同一网格、独立部件、modifier/实例；可作为刚性附属件随整体运动，但必须参与净空/碰撞检查。不能声称会弯折或断裂，也不能无碰撞穿过桌面 |
| R：唯一桌沿接力物 | 由收音机带动后独自跌落，不能由球绕过收音机直接命中。优先实测 Paper Mario 小盒；不合适再比较另一款真实紧凑包装 |
| 地面链 | 目标约 24–36 个总动态体，具体数量由真实尺寸/接续决定；沿已勘测区域形成缓弯路线，不强凑旧 36 体数量 |
| 异形接力 | Shurtape 必须在链中有可见转动/滚动，并接触触发下游；不能只是装饰品或把洞填成实心圆柱 |
| 多样性 | 提议至少 6 种新增资产型号，加原生收音机；至少包含球形、环形、薄盒、厚包装四类外形。具体名单在 G1 冻结 |
| 摄影 | 单镜头：先清楚看到球→收音机→R，提前转向桌沿跟随落体，然后沿地面反应前沿平滑移动；不靠突然切镜、远景或遮挡掩盖交接 |

“收音机不掉下桌”并不自动保证天线安全。阶段一先检查完整倾倒扫掠体和桌面的支撑范围；阶段二以真实运动验证。若只有拆/缩天线、钉住机身或搬收音机才能成立，停止并单列变更申请，不能替用户决定。

- A 留在桌上，无锚定、隐形挡块、定时释放或碰撞后额外推力；天线没有穿入几何。无法模拟弯折不等于允许无视接触。
- R 真正离桌自由下落触发地面链；去掉 A 后 R 不应被 B 直接触发；去掉 R 后地面链不启动。
- 胶带有明显转动，并主动接续下游。优先可辨的至少约四分之一圈转动；实际距离依据原地面决定，不能靠贴图自转假装滚动，不能整环凸包封孔。

- 负例必须能被拒绝：3 mm 几何偏移/穿透、胶带孔被凸包填平、收音机静态副本残留、Fog 机位不同、相机距离查询失败。
