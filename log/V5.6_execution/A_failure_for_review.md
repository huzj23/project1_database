## 3. 闭式论证（impasse）

木板靠墙、脚落在**罐子可达**的地面上，则必须横跨台座边缘（x = −2.000）到墙（x = −2.160）之间的 **0.160 m**：

```text
sin(theta) >= 0.160 / upright_extent
```

对推荐木板 `board_01_wooden_boards_001_c04`（实测竖直边长 **0.387728 m**）：

```text
theta >= asin(0.160 / 0.387728) = 24.37 deg
theta >= 约 31 deg（若要求罐子接触高度处的板面也越过台座边缘）
```

**关键点是：木板质量在这一判据中被消掉。** 罐子需要传给木板的角速度：

```text
dE = m_b * g * (L/2) * (1 - cos(theta))       木板需获得的势能
I  = m_b * L^2 / 3                            绕脚转动惯量
omega_needed = sqrt(3 * g * (1 - cos(theta)) / L)    与木板质量无关
```

但罐子实际能传递的是动量，而木板在接触点处的**等效质量**为 `M = I / h^2`。滚动圆柱与竖直面接触于其中心高度 h = r：

| 罐子 | h | M = I/h² |
| --- | --- | --- |
| d = 0.130 m | 0.065 | **45.6 kg** |
| d = 0.150 m | 0.075 | **34.3 kg** |

在 26.2° 可达倾角下，0.2184 kg 的罐子只传递了所需角速度的 **0.313 倍**（差约 3.2 倍），与 135 次试验 0 次成功一致。

## 8. 请评审者判断的可修复方向

以下三个方向都会**改变任务定义**，因此属于需要决策的选项，而不是可以擅自实施的技术修补：

1. **移除台座台阶**。那 50 mm 台阶是一道排水台座，非结构承重。移除后木板可以约 12° 倾角、脚落在开阔地面上——这正是 `a29` 实测确实推倒过的配置（最大 85.9°，保持 1.71 s）。这是最直接的修复，但改动了场景。

2. **改撞场景内另一个非靠墙的物体**。巷道地面 x = −1.90 … −0.90 的 1.0 m 平坦段是真实的、可用的；若目标物体不是被墙撑住的薄板（例如独立站立的箱体或罐体），则不存在本文件的斜坡几何问题。但被撞物体不再是原定的拆分布板。

3. **保持原设定，接受这是场景的物理极限**。若评审认为 24.4° 最小倾角这一闭式关系无法通过调整资产参数绕过，则本视频在本场景下应判定为不可达。

供评审者复核的关键量：**竖直边长 0.387728 m** 与 **0.160 m 间隙**之比决定 24.4°；这一比值是几何事实，与质量、速度、罐子尺寸均无关。若评审认为存在绕过方式，请指出本文件哪一项测量有误，对应的复现脚本均已列出。
