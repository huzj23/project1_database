## 3. 重启后的恢复步骤（约 30 秒）

本机不需要装任何东西——工具链已就位。直接执行：

```powershell
cd D:\workspace\project1_database
python tools\ssh_ctl.py run --cmd "bash /data/raw/huzijian/project1_database/tools/status.sh"
```

看到批次状态即表示通道正常。常用命令：

| 命令 | 作用 |
|---|---|
| `python tools\ssh_ctl.py run --cmd "bash <WS>/tools/status.sh"` | 批次总览（完成数、日志尾部、磁盘） |
| `python tools\ssh_ctl.py run --cmd "bash <WS>/tools/load_check.sh"` | 服务器 GPU/CPU/内存负载 |
| `python tools\ssh_ctl.py run --cmd "bash <WS>/tools/delivery_report.sh"` | 交付清单（文件数/体积/耗时） |
| `python tools\fetch_outputs.py --what small` | 只取视频+元数据+缩略图（约 12 MB） |
| `python tools\fetch_outputs.py --what full` | 取全部帧（约 3.8 GB） |

> `<WS>` = `/data/raw/huzijian/project1_database`

**安全护栏**：`tools/ssh_ctl.py` 会在建立连接前校验命令，任何指向工作区之外的路径
一律拒绝（已通过 11 项自测）。重启后行为不变。
