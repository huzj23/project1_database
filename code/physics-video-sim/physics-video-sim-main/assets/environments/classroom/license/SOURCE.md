The official Blender page describes this as the 72 MB Classroom demo. The
project keeps the original archive and extracted `.blend` dependencies under
`source/`. `visual/scene.blend` was produced with Blender 3.6 by baking world
transforms, joining the visual meshes into the one object expected by Kubric,
and packing all 50 file textures. The source scene was not simplified.
